# 在线维护隔离（#237）

[English](README.md) · **简体中文**

在固定的 Release 引擎 `9861140f5ee66459ffce31908a5aa9f02eada5b9` 上，
用两个合成集合运行同一份本地 HTTP 读写计划。每个场景使用新数据根并启动新的环回服务。
夹具起始状态包含热点集合 1,024 条记录、邻居集合 64 条记录，以及由备份继续持有的已删除热点
旧代次 512 条记录。每个集合的两条读通道交替执行点读和词法查询，另有一条通道负责追加。
请求按固定偏移发出，测量期间没有重试。报告记录前一个请求占用通道造成的发起偏差。

## 运行

使用 Linux、Python 3.11+、`taskset` 和支持 `--kill-on-exit` 的 `strace`。
需要能够跟踪本次启动的子进程。选两个可用 CPU，并为新输出目录保留至少 1 GiB。
运行保留可丢弃库及原始系统调用日志。在固定引擎检出中编译默认特性的 Release 二进制，
从夹具检出目录运行下列命令。

```bash
cargo build --locked --release -p anyseek --bin anyseek_server
python3 benchmarks/maintenance-isolation/measure.py \
  --server /path/to/pinned-engine/target/release/anyseek_server \
  --engine-sha 9861140f5ee66459ffce31908a5aa9f02eada5b9 \
  --cpus 0,1 --out /tmp/anyseek-237-run1 --with-crash
```

`--case` 只用于探索性单场景检查。完整对照运行四个场景，使用相同的请求槽位和起始权威数据。
对照、索引和回收场景在装载后对热点派生视图建立 checkpoint。压实场景保留可变组件，
由相同的追加流量触发生产合并。复跑时核对夹具及二进制哈希、引擎 SHA、请求计划哈希、
CPU 绑定、文件系统和跟踪器版本。

## 覆盖证据

| 场景 | 必须观察到的证据 |
| --- | --- |
| 对照 | 测量期内未观察到目标索引构建、合并构建或旧目录删除。备份仍保护旧代次。 |
| 索引构建 | 热点真实 `PATCH /api/v1/index/hot` 返回索引序号，请求期内有同序号的 `anchor_prepare` 阶段。 |
| 缓存压实 | 观察到原生合并捕获、构建、安装及后台工作器完成安装；构建期内成功写入热点当前代次的新原生缓存。 |
| 回收 | 删除旧备份解除保护，旧代次目录被重命名，并发生指向该代次的成功文件或目录删除，最终确认其消失。 |
| 可选进程故障 | 邻居写入确认后，在旧热点代次仍被备份保护时杀死服务。重开保留两个当前集合及备份保护，旧删除和邻居写入可按原回执重放，解除保护后实际回收旧热点代次。 |

每个有维护的场景均要求**两个集合**都至少有一个读请求与证实的维护窗口重叠。
阶段起止时间来自被跟踪的服务日志写入。回收窗口采用每次成功
`unlink`、`unlinkat` 或 `rmdir` 的实际时间，不计重命名或删除调用之间的间隔。
只有保守的 HTTP 在途区间与窗口相交，才计入重叠。采样的墙钟与单调钟偏移变化超过
2 ms 时，覆盖判定失败。点读、词法命中和成功追加会通过真实服务检查身份、版本及文档或正文。

## 读取结果

- 查看顶层及各场景的 `report.json`。对比全量请求、实际重叠请求以及对照组的相同请求槽位。
  结果按集合和操作提供尝试数、成功比例、nearest-rank 成功 p99、HTTP 429、逐项 Busy 及
  HTTP 503 错误码。HTTP 200 追加只有在每项都返回已应用回执时才算成功。成功 p99
  不计失败请求，429 和 503 分开统计。
- 场景报告记录证实的维护窗口长度，以及观测到的索引请求到阶段、合并工作器启动到捕获、
  解除 pin 到首次删除的等待。缺少服务调度事件时，调度到捕获的字段留空。原始证据位于
  `requests.jsonl.gz`、`events.json`、`server.log` 和 `syscalls.*`。
  原因以服务的显式证据为准。普通 Busy 响应不能区分预算、文件 I/O 或发布重验。
  请求级原因由现有的 [#238 诊断](https://github.com/TheLudlows/anyseek/issues/238)覆盖。
- `resources.json` 保存进程 RSS/高水位和库目录、`TMPDIR` 的已分配块采样。
  磁盘按路径统计，周期采样可能错过短时峰值。
- 退出码零表示场景覆盖及夹具断言成立。延迟与可用性判断另看计数及样本数。
  这是小样本跟踪回归。正文日志重打包、无跟踪吞吐、持续饱和、生产 SLA 及独享 NVMe
  矩阵超出本夹具证据范围。

夹具复用共享 HTTP 客户端，为已有的[回收冒烟](../../scripts/record_reclamation_smoke.py)
补充热点与邻居并发流量，以及解除保护前的可选进程故障。
