# 检索引擎职责收敛

AnySeek 的边界是可靠、可更新的全文与向量检索。原文、向量、普通元数据、稳定 Record ID、Absent/Any/Match、有限窗口幂等与查账、异步索引进度、WAL/恢复/检查点/备份、安全回收与资源预算保留。中文全文、ANN、全文向量 RRF、过滤、Top-K、分页和评分保持。

来源版本、切块、证据依赖、派生重算、业务关系及记忆策略由应用负责。document_id/chunk_index/章节/source_id/source_version 等仍可作为普通 document 字段保存。旧版正文摘录和字节/页定位不属于引擎 API。

## 实施状态

第一阶段撤下顶层 system 写入、evidence/entities/neighbors 路由、relation_fusion 查询及其 OpenAPI/控制台入口，保留普通元数据和通用全文向量 RRF。内部旧模型及保护校验暂时保留，下一阶段删除；当前不是完成全部职责收敛或已证明性能收益。

后续顺序：删除内核来源历史/依赖/定位符和专用关系融合；TTL 改为到期不参与检索、后台回收并说明时间/重启/回退边界，不承诺隐私彻底删除；收敛有界回执；控制所有 State 修改入口后，用受影响数据与提交基准重验替换普通提交全量 proof。恢复/维护/诊断必要校验、未知结果和备份保护不能先行删除。

当前 TTL 仍使用原不可逆持久转换，不应把计划中的后台回收和 ID 可重用描述成已经实现。当前回执仍是原重试窗口及历史 GC 策略。完整性能对照将使用独立保存的 master024d9d9基线和本次最终版本；不复用536候选数字。

不支持旧格式升级、迁移、SQL/JOIN或自动合并。本地分支不代表已发布功能。

`/doc/{record_id}/status` 保留为技术状态接口，用于当前版本和 pending_vector_fields；专用来源业务状态将在内核阶段移除。
