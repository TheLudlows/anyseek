# Record 语义与一致性

HTTP 请求、字段、配额和操作示例以[服务指南](../anyseek/server/README.md)为准；本文保留实现必须维持的不变量。当前交付状态见 [STATUS](../STATUS.md)，持久化见[存储协议](storage.md)。

## 身份、版本与重试

`record_id` 是 collection 内稳定身份，内部 DocID 仅为索引地址。`routing_key` 首次绑定后不可改变；删除保留墓碑，重建继续递增版本，旧条件不能因 ID 复用而接受新内容。`document` 是完整替换，显式 null 表示删除；`schema.store` 只控制搜索投影，不影响原始数据持久保存。

客户端在发送前保存完整 `operation_id` 与语义请求。同一身份和相同请求返回原回执，不重复推进版本；同一身份改变内容冲突。支持窗口为当前及前一 UTC 日，持久 epoch 水位阻止时钟回退复活请求。超时、回执缺席、过期及后续拒绝都不能证明早先请求未提交，不应换 ID 猜测补写。

| 结果 | 语义与处理 |
| --- | --- |
| 成功 | 权威已持久且共同视图可见；staging 成功只保证私有成员持久，须显式 Publish |
| rejected / conflict / busy | 描述本次校验、条件或准入结果；不解除早先未知状态 |
| outcome_unknown | 持久化或响应结果不明确；恢复后以原身份查账/重试 |
| durable_pending | 权威已持久、派生应用未完成；实例封锁并等待恢复 |
| recovery_required / storage_error | 不能继续可信服务，不回退旧缓存或重置空库 |
| operation_expired | 已超支持窗口，不能用新操作身份推断补写 |

持久工作由独立持有所有权的任务接管；HTTP 取消不撤销已接受工作。配额覆盖原始记录、完整恢复闭包、操作回执及后台构建，不只是当前可见正文。

## 来源、generation 与时间

来源和关系引用精确版本。来源删除、stale、generation 切换与 TTL 共用可见性规则，查询、回表、解释和最终输出不能绕过隐藏。来源旧修订仍可能按既有证据协议读取，不能仅因没有当前引用就回收。

Begin/StageBatch 只写私有成员；Seal 认证完整清单；Publish 原子切换整代成员与活动统计。Abort/租约到期清理私有正文，但保留精确重试需要的摘要回执。向量后补以精确版本为前提，物理 payload 身份不能只用正文版本表示。

一次查询固定 `evaluation_time`，TTL 过期通过权威决定形成不可逆墓碑。响应期间单纯经过时间期限不要求改变固定视图；后续请求观察已提交的过期结果。feed 是内容无关的至少七天通知，容量不足背压，不提前丢事件；scope 或 floor 失效须重新 bootstrap。

## 授权、恢复与接管

catalog 保存 key、collection、grants 与控制回执，身份生命周期独立于数据。全局授权屏障确定撤销和写入的顺序；OutputPermit 在响应及 body frame 交付复核 revision，撤销后重新授权不能复活旧响应。服务不能缓存授权决定作为永久许可。

独立备份不证明备份后没有删除；恢复保留版本与回执、更新 feed scope，并维持独立快照/证据隔离，不复活旧 grants。完整服务恢复仅开放当前 master，历史身份禁用。

同服务受控接管必须认证当前源的完整最终状态，永久封存源，目标包含所有已确认后续操作，再由 catalog 激活。备份是来源证明而非回滚点。缺少最新可信删除历史、源仍能输出或权威状态无法认证时继续隔离；没有强制解锁或跨服务双活入口。

每个 collection 一个 partition。没有跨 collection 事务、来源依赖、SQL/JOIN、完整图语言或旧格式迁移。Linux/Windows 进程故障回归不替代系统崩溃与断电验收。
